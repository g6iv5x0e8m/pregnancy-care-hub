# 孕前致畸五项与优生五项的检查内容都是一样的吗？

> 更新时间：2026-09-10 (UTC+8)

女，33岁，刚结婚半年，婚后就开始积极备孕，我听朋友说我这个年龄怀孕一定要做好孕前检查，去医院了解需要做致畸五项，我看有的姐妹又是做的优生五项，第一次备孕生孩子对这些都不了解，想问一下致畸五项和优生五项的检查内容包括哪些？它们是一样的吗？

孕前致畸五项与优生五项一般没有什么区别，检查内容也是从差不多的。致畸五项与优生五项的检查内容包括有弓形虫、风疹病毒、巨细胞病毒、单纯疱疹病毒和其他病毒的检查，这些病毒会通过胎盘传给胎儿，影响胎儿的生长发育，严重的可能会还会导致流产、早产、发育不良、畸形的不良妊娠结果，所以是有必要做这项检查的。

致畸五项和优生五项检查又被叫做torch五项检查，这项检查报告每个项目都有IgG和抗体IgM两项指标，如果结果显示为阳性，需要经过治疗后才能进一步的备孕工作。下面带大家详细了解一下致畸五项（优生五项）的检查内容：

- 1. 弓形虫，感染途径是被动物体液或者粪便污染过的食物，可通过胎盘感染传给胎儿，造成胎儿死亡、脑积水、神经系统发育障碍等；
- 2. 风疹病毒，兔或猪等动物的鼻咽分泌物的飞沫进行传播，孕妇感染该病毒会对胎儿造成伤害，如导致胎儿患上先天风疹性白内障、心血管疾病、小头畸形等
- 3. 巨细胞病毒，能够侵入人体内脏和淋巴系统，孕妇被感染后可能会导致胎儿发生黄疸、溶血性贫血等，该病毒也是新生儿畸形、智力迟钝和先天性耳聋的首要危险因素；
- 4. 单纯疱疹病毒，会引起生殖器的皮肤黏膜的感染，感染几率高，若孕妇为原发性疱疹，胎儿有46%-60%的几率被感染，易导致胎儿小眼畸形、脑膜炎、脑炎等；
- 5. 其他病毒，包括人乳头瘤细胞感染、衣原体、柯萨其病毒等，以及其他一些病毒感染等。
torch五项检查一般是在孕前就要完成，怀孕后就不要检查了，torch的检查时间在计划怀孕3-6个月前比较合适。这项检查在一般的医院都可进行，不过不同医院价格不同，优生优育torch五项检查费用大概在400元左右，具体以当地医院为准。
