# 河大附院做试管婴儿的费用贵不贵，贵不贵看过来人怎么说

> 更新时间：2026-09-11 (UTC+8)

由于试管婴儿流程步骤比人工授精多，大致可分为进周促排、促排卵取精、胚胎培养、检测与移植等，所以涉及到不同的阶段其费用会存在差异，本身做试管婴儿的费用是除流程、成功率外，姐妹们最为关心的几个问题，这里就有一份有关河大附院人工授精的费用清单明细：

河北大学附院生殖医院开展生殖外科手术多年，同时具有中西医结合疗法及辅助生殖技术，治疗女性月经失调、多囊卵巢综合征、泌尿生殖器炎症等各种原因所致的不孕不育疾病，由此很多打算赴河北大学附院做试管婴儿的人群也充满了各种疑问，这里围绕河北大学附院试管婴儿费用、具体收费标准、技术水平等收集，整理成文，为更多不孕不育家庭在医院选择上提供参考。

## 2024河北大学所属医院试管婴儿费用明细

- 1. 8月14日：第一次就医，做人工授精前，医生说需要做术前检查，检查项目基本上大同小异，女方检查花费1312元，男方检查花费533元，挂号费一共34元；
- 2. 9月15日：挂号费12元，白带检查花费20元，输卵管造影检查花费218元，加上其他费用一共491.46元；
- 3. 11月08日：月经第四天去医院做超声检查看基础卵泡数量，开始促排，B超检查花费70元，挂号费12元，输血前八项检查花费592.16元，加上其他费用一共花费1645.68元；
- 4. 11月19日：挂号费12元/次，一共去了4次医院，尿促药物花费24.17元/针，B超花费70元/次，促排期间一共花费400.5元；
- 5. 11月20日：挂号费一共24元，绒促药费30.27元，人工授精手术费280元，B超花费70元，精液优化640元，加上其他费用一共花费1168.19元。

女性如果是不明原因不孕，需要做三次人工授精手术(AIH)都没有成功的前提下，才可以做试管婴儿(IVF-ET)，而试管婴儿的过程包括术前检查、促排卵治疗、促排卵取精、胚胎移植到黄体安胎，在河北大学附院做一次人工授精总共花费约5584.84元，其中不包括生活费、交通费、还有验孕等费用。

每个人促排方案不同，促排药物和剂量也不一样，所以花费也不同哦，以上是单单某个人长方案促排做一次人工授精的花费情况，仅作参考!通常河北大学附院人工授精一个周期是5千-1.5万，一个周期不成功的话，人工授精费用可能会超过2万。
